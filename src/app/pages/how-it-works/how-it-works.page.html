Les étapes 1 à 3 sont déterministes : la même question retrouve les mêmes passages. L'étape 4 ne l'est pas strictement : une température basse réduit les variations sans les supprimer.

Ce que l'IA reçoit vraiment

Elle ne voit ni la documentation entière, ni d'autres conversations : seulement les passages retenus par la recherche, la question, et ces consignes. Si les extraits ne contiennent pas la réponse, elle doit le dire.

Une réponse peut malgré tout être imparfaite : c'est pourquoi chaque affirmation renvoie à une source que tu peux vérifier.

Confidentialité et transparence

La question et les passages trouvés sont envoyés à l'API DeepSeek pour rédiger la réponse : n'y saisis aucune information confidentielle. L'app n'a pas de base de données ni de comptes : les questions ne sont gardées que dans la mémoire du serveur, jusqu'à 24 heures. Le code source est public.
